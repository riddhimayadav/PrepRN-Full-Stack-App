# PrepRN — earlier application snapshot

**Newer development: [riddhimayadav/PrepRN](https://github.com/riddhimayadav/PrepRN).**

This repository preserves an earlier version of PrepRN, a meal-planning and restaurant-discovery application built with Flask, Jinja templates, SQLAlchemy, and SQLite. It integrates Yelp, Spoonacular, and Gemini through modules in one Flask application.

The newer repository contains additional pantry, preference, and recommendation features and the maintained setup and test instructions. Existing links to this snapshot remain available.
